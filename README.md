# ST Jewelry

ແອັບ POS ສຳລັບຮ້ານເຄື່ອງປະດັບ (jewelry) — ສ້າງຈາກໂຄດ ST POS ຂອງ TaoSivi, ຕັດເປັນແອັບແຍກສະເພາະ jewelry.

## ຟັງຊັນສະເພາະ jewelry
- ສິນຄ້າລາຍຊິ້ນ: 1 ຊິ້ນ = 1 ລະຫັດ/ບາໂຄດ, ວັດສະດຸ, ນ້ຳໜັກ, ຫີນ, ຂະໜາດ, ໄລຍະຮັບປະກັນ
- ພິມໃບຮັບປະກັນໃຫ້ລູກຄ້າ
- ສະແກນບາໂຄດ, ສະຕ໋ອກ, ຂາຍ (ໃຊ້ລະບົບ ST Mart)
- ໝວດລາຍຈ່າຍ: ໂຄສະນາ (Ads), ຄ່າຂົນສົ່ງ/ຫຸ້ມຫໍ່, ຄ່າທຳນຽມ TikTok/FB, ເຄລມ/ສິນຄ້າເສຍຫາຍ, ອຸປະກອນຖ່າຍທຳ
- **ລາຍງານ → ແບ່ງກຳໄລ (ຫຸ້ນສ່ວນ)**: ກຳໄລສຸດທິ = ຍອດຂາຍ − ຕົ້ນທຶນສິນຄ້າທີ່ຂາຍ − ຄ່າໃຊ້ຈ່າຍ → ແບ່ງນາຍທຸນ/ຜູ້ບໍລິຫານ (ຕັ້ງ % ໄດ້, ເລີ່ມຕົ້ນ 50/50), ກັນທຶນໝູນວຽນ, ROAS, ທຶນຄ້າງສະຕ໋ອກ, Export Excel/PDF
  - ການຊື້ສະຕ໋ອກບໍ່ນັບເປັນຄ່າໃຊ້ຈ່າຍ (ເປັນທຶນ → ຕັດເປັນຕົ້ນທຶນຕອນຂາຍ)
  - ອຸປະກອນຖ່າຍທຳ ບໍ່ຫັກ ເວັ້ນແຕ່ຕິກ "ຫັກອຸປະກອນຖ່າຍທຳເປັນຄ່າໃຊ້ຈ່າຍ"

## ໄຟລ໌
`index.html` (ແອັບທັງໝົດ) · `sw.js` · `manifest.webmanifest` — ວາງໄວ້ໃນໂຟນເດີດຽວກັນໃນ server.
ລອງແບບ demo (ບໍ່ມີ server): ເປີດ `index.html?demo=jewelry` (Admin PIN ສະແດງໃນໜ້າ demo).

## ສ້າງໃໝ່ຈາກ ST POS
ຢ່າແກ້ `index.html` ໂດຍກົງ. ແກ້ໃນ ST POS ແລ້ວ ລັນ `python build.py --app jewelry` (ຢູ່ໃນໂຟນເດີ ST Mart).
